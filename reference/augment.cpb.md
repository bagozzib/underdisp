# Augment data with CPB fitted values (broom method)

Augment data with CPB fitted values (broom method)

## Usage

``` r
# S3 method for class 'cpb'
augment(x, ...)
```

## Arguments

- x:

  A `"cpb"` object.

- ...:

  Unused.

## Value

A data frame with fitted values, response residuals, and the implied
per-observation ceiling.
